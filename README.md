# PortSwigger Labs

This repository documents my learning journey through the **PortSwigger Web Security Academy**.

The purpose of this repository is to improve my web application security skills by studying, practicing, and documenting common web vulnerabilities in a controlled lab environment.

> **Note:** All testing documented in this repository was performed only on the official PortSwigger Web Security Academy labs for educational purposes.

---

## Learning Objectives

- Understand common web application vulnerabilities
- Learn manual web penetration testing techniques
- Improve Burp Suite skills
- Practice vulnerability assessment and reporting
- Build a professional cybersecurity portfolio

---

## Topics

- Authentication
- SQL Injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Server-Side Request Forgery (SSRF)
- File Upload Vulnerabilities
- Path Traversal
- Cross-Origin Resource Sharing (CORS)
- API Testing
- GraphQL
- NoSQL Injection
- WebSockets
- Race Conditions
- Web Cache Deception
- Prototype Pollution
- Clickjacking
